# Course 1: Welcome — Develop Agents with Agent Development Kit (ADK)

This is the introductory course in the Google Skills learning path for developing agents with the Agent Development Kit (ADK). It sets the foundation for the rest of the path by explaining what the GEAR program is, what production-ready AI agents look like, and how ADK helps teams move beyond basic prototypes into more robust, secure, and scalable agent development.

## Course overview

This short introductory course is designed to orient learners before they start building. It frames the bigger learning journey and helps answer three key questions:

- What is an AI agent in a production context?
- Why does Google’s Agent Development Kit matter?
- What will I learn across the rest of this path?

## Why this course matters

Most teams can prototype a chatbot quickly. The bigger challenge is building an agent that is reliable, secure, observable, and able to interact with real tools and systems. This course introduces that shift from experimentation to production-minded agent engineering.

## Learning objectives

By the end of this course, learners should be able to:

- explain the purpose of the GEAR learning program
- describe the value of production-ready AI agents
- understand the broad ADK workflow for building agents
- recognize the major concepts covered in later courses
- prepare for hands-on implementation in the next course

## Core ideas introduced in the course

### 1. GEAR and the broader learning journey
The course introduces the Gemini Agent Ready (GEAR) initiative as a structured path for learning how to build agents that are useful in real-world enterprise settings.

### 2. From prototyping to production
A simple prompt-and-response model is not enough for many real business scenarios. This course highlights the need for agent design patterns that include tool use, context management, security, and lifecycle thinking.

### 3. Agent Development Kit (ADK)
ADK is the toolkit that helps developers structure agent behavior, add capabilities, manage memory, and orchestrate tool-based workflows. It provides the foundation for later labs and course modules.

### 4. What the rest of the path covers
The welcome module previews the later sequence, including:

- building a first agent
- adding tools
- managing memory and state
- optimizing behavior
- integrating with MCP-based services
- completing a skill badge challenge

# Lab 04: Optimize Agent Behavior

## Goal
Improve agent quality by refining instructions, model choices, and planning patterns.

## Objectives
- refine system instructions for clarity and scope
- evaluate model behavior with targeted prompts
- test structured reasoning and planning patterns
- improve reliability and action quality

## Deliverable
A more controlled agent that behaves consistently and follows instructions more precisely.

## Suggested tasks
- compare different prompt setups
- add constraints and response formatting rules
- evaluate edge cases and failure modes
- document which strategies improved output quality

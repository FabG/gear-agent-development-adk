# Lab 05: Add Currency Tools to an Agent using MCP

## Goal
Connect the agent to an external tool or service using the Model Context Protocol (MCP).

## Objectives
- understand the role of MCP in tool-based agent architectures
- connect an agent to a service-backed tool server
- design structured calls and expected outputs
- validate end-to-end tool invocation

## Deliverable
An agent that can access a real external tool through MCP and use it to complete a task.

## Suggested tasks
- set up a lightweight MCP server or example service
- expose a weather, currency, or data-oriented tool
- verify the agent can call the tool correctly
- review how protocol-based integration differs from direct API calls

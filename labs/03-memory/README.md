# Lab 03: Manage Agent Memory and State

## Goal
Teach the agent to maintain context across turns and behave more like a personalized assistant.

## Objectives
- manage session state
- preserve user preferences and context
- design stateful interaction patterns
- evaluate how memory affects utility and reliability

## Deliverable
A conversational agent that keeps track of meaningful context across multiple prompts.

## Suggested tasks
- add a user profile or preference store
- maintain recent conversation state
- test how the agent behaves across multi-turn scenarios
- document trade-offs between short-term and long-term memory

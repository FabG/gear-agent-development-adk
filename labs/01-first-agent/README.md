# Lab 01: Build Your First Agent

## Goal
Create a simple Agent Development Kit (ADK) agent that can respond to a user prompt and run within a local development environment.

## Objectives
- configure the local environment
- create a basic agent definition
- run the agent interactively or via a small script
- verify output and behavior

## Deliverable
A working minimal agent that can respond to prompts and serve as the base for future labs.

## Suggested tasks
- install dependencies and confirm the environment works
- define a basic system prompt and model configuration
- run the agent against a few sample prompts
- record observations about latency, behavior, and reliability

## Notes
This lab is the foundation for the rest of the path. Keep the implementation simple and easy to debug.

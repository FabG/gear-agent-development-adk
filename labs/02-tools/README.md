# Lab 02: Add Agent Capabilities With Tools

## Goal
Extend the agent with practical tools so it can perform actions beyond text generation.

## Objectives
- identify useful tool actions
- integrate one or more tools into the agent
- validate tool invocation and result handling
- document the pattern for future integrations

## Example capabilities
- search or retrieval
- API calling
- custom local utilities
- code execution or environment actions

## Deliverable
An agent that can call tools in response to a user request and return actionable results.

## Suggested tasks
- add a simple tool interface
- define tool arguments and structured outputs
- test multiple user requests
- verify that the agent chooses the correct tool when needed

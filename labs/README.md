# Lab Index

This folder contains the hands-on exercises that align with the Google Skills path for developing agents with the Agent Development Kit (ADK).

## Lab sequence

- `01-first-agent` — build a basic ADK agent and confirm it runs
- `02-tools` — add useful tools and action capabilities
- `03-memory` — implement session memory and conversational state
- `04-optimization` — improve prompts, planning, and agent behavior
- `05-mcp-tools` — connect an agent to an external service using MCP
- `06-skill-badge` — final review and skill badge preparation

## How to use these labs

1. Start with the first lab and complete in order.
2. Capture outputs, prompts, and examples as you progress.
3. Treat each lab as a practical building block for the final artifact.
4. Use your completed project as a portfolio example for AI agent engineering.

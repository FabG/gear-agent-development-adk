# Course Curriculum: Develop Agents with Agent Development Kit (ADK)

This curriculum is based on the Google Skills learning path for developing production-minded AI agents using Google’s Agent Development Kit (ADK).

## Learning objectives

By the end of this path, learners should be able to:

- set up and run a local ADK development environment
- build a simple AI agent from first principles
- add tools and integrations to extend agent capabilities
- manage memory and conversational state
- optimize prompt design and agent behavior
- connect agents to external tools using MCP
- prepare for a skill-badge certification experience

## Module sequence

### 1. Course Welcome
Focus: orientation, goals, and program context

Topics:
- introduction to the GEAR learning journey
- production-ready AI agent foundations
- overview of the ADK approach

### 2. Build Your First Agent with ADK
Focus: hands-on implementation

Topics:
- environment setup
- creating an agent definition
- basic configuration and execution
- simple agent invocation and testing

### 3. Add Agent Capabilities With Tools
Focus: turning an agent into an assistant

Topics:
- tool calling patterns
- web and custom actions
- integrating practical capabilities
- deterministic operational patterns

### 4. Manage Agent Memory and State
Focus: multi-turn intelligence

Topics:
- session state and context retention
- user preferences and personalization
- memory strategies for conversational agents
- stateful agent design

### 5. Optimize Agent Behavior
Focus: better reasoning and more reliable responses

Topics:
- advanced instructions
- model selection
- planning and orchestration
- structured guidance for quality and reliability

### 6. Add Currency Tools to an Agent using MCP
Focus: practical integration with an external tool server

Topics:
- Model Context Protocol fundamentals
- connecting an agent to a service through MCP
- structured tool invocation patterns
- building real-world tool-integrated agents

### 7. Skill Badge: Engineer AI Agents with ADK
Focus: capstone validation

Topics:
- applied agent engineering
- implementing a solid multi-step solution
- demonstrating practical skills in agent design and execution

### 8. Wrap-up and next steps
Focus: continue the learning path

Topics:
- reviewing achievements
- identifying advanced next steps
- branching into deployment, scaling, and enterprise agent patterns

## Lab plan

| Lab | Focus | Outcome |
| --- | --- | --- |
| 01-first-agent | Setup and basic agent | A working agent that responds to prompts |
| 02-tools | External tools | Agent can invoke useful actions |
| 03-memory | State and context | Agent maintains continuity across turns |
| 04-optimization | Prompt and behavior tuning | Better reliability and reasoning |
| 05-mcp-tools | Protocolized tool access | Agent uses an MCP-backed service |
| 06-skill-badge | Capstone review | Final practice and project validation |

## Assessment approach

Learners can validate their understanding by:

- running the labs in sequence
- verifying the agent behavior end-to-end
- testing tool invocation and observable outputs
- reviewing memory persistence and session flow
- measuring whether model instructions produce the desired results

## Suggested outcomes

Successful completion of this path should result in a learner who can:

- build and explain an ADK agent
- connect tools and data sources
- maintain conversational memory
- intentionally tune system behavior
- work with MCP ecosystems
- produce a practical, portfolio-ready AI agent project
